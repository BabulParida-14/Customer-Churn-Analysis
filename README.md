# 📊 Customer Churn Analysis

## 📌 Project Overview

This project focuses on analyzing customer churn in the telecommunications industry using Python, Pandas, and Microsoft Power BI.

The main objective is to understand customer behavior, identify factors associated with customer churn, and provide actionable business recommendations to improve customer retention.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Power BI
- SQLite
